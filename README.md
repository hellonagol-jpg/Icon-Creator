Features:

Image Uploads: Upload custom art with zoom and position controls.
Backgrounds & Borders: Selection of textures and frames with adjustable hues and brightness.
Text Engine: Support for up to 3 lines of text with custom fonts, rainbow shaders, and glow effects.
Layered Decorations: Add overlays with precise scaling and manual positioning.
Visual Effects: Adjustable CRT scanlines and glitch modes including chromatic aberration and static noise.
Sharing System: Export and import designs as portable .icontemplate bundles.
Library Expansion: Support for adding custom fonts, borders, and backgrounds directly to the app folders.
